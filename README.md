# 寶寶症狀 3D 圖解

| 資料夾 | 內容 | 狀態 |
| --- | --- | --- |
| `baby-symptom-3d/` | 3D 前台（Vite + Three.js），一般症狀＋早產兒對比 | 可執行：`npm install`、`npm run dev` |
| `baby-symptom-api/` | Java 後端（Spring Boot）與管理表單 | 目前用 H2 開發資料庫；尚未改成 SQL Server、尚未包含資料來源表 |
| `sqlserver/` | SQL Server 建表、示範資料、CSV 匯入程序、Excel 填寫範本、關聯圖 | 可在 SSMS 執行（尚未在真實 SQL Server 測試過） |

各資料夾裡的 README 有詳細說明。

> 症狀內容為示範，正式公開前請由兒科醫護審閱。
